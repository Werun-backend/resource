# 后端工程师副业指南

> 本文面向已拿到大厂 offer、即将入职的应届后端工程师，提供切实可行的副业方向与建议。

## 背景

入职大厂之后，工作之余仍有一些可利用的时间与资源。结合后端工程师的技术背景，以下几个方向相对容易上手，风险低、收益可预期。

---

## 一、接私活（接外包项目）

**适合人群**：有完整项目开发经验、能独立完成从需求到上线的同学。

**平台推荐**：
- [猪八戒网](https://www.zbj.com/)
- [程序员客栈](https://www.proginn.com/)
- [码市](https://codemart.com/)
- [BOSS直聘（兼职）](https://www.zhipin.com/)
- 微信/QQ群、熟人介绍

**常见需求类型**：
- 小程序 / App 后端接口开发
- 企业管理系统（OA、ERP、CRM）
- 电商平台搭建
- 数据爬取与处理脚本

**建议**：
1. 优先选择需求明确、周期短（2～4 周）的项目，降低烂尾风险。
2. 签订简单合同，约定付款节点（如 30% 定金、验收付尾款）。
3. 刚起步时报价可以稍低，积累好评后逐步提高单价。
4. 避免接需求模糊、甲方频繁改需求的项目。

---

## 二、技术内容创作

**适合人群**：善于总结、表达能力较强的同学。

### 2.1 技术博客 / 公众号

- **平台**：掘金、CSDN、知乎、个人博客（Hexo/Hugo）、微信公众号
- **变现方式**：广告分成、知识付费、接软文推广、引流接外包

**建议**：
1. 选定垂直领域（如 Java 并发、Go 微服务、MySQL 调优），持续输出高质量文章。
2. 初期重点在掘金/知乎积累曝光，再考虑开通公众号。
3. 每周 1～2 篇的节奏可持续性强，不必追求高频更新。

### 2.2 录制视频课程

- **平台**：B 站（免费引流）、慕课网、极客时间、网易云课堂
- **变现方式**：付费专栏、打赏、接广告

**建议**：
1. 先在 B 站免费发布积累粉丝，达到一定体量后发布付费课程。
2. 选择"新手向"题材（如 Spring Boot 项目实战、Redis 入门）受众更广。
3. 录制设备要求不高，一块好的麦克风比摄像头更重要。

---

## 三、开源项目 / GitHub 变现

**变现方式**：
- GitHub Sponsors（国际用户打赏）
- 开源项目商业版 / 定制开发
- 通过开源项目建立个人品牌，吸引外包或求职机会

**建议**：
1. 选择一个实际痛点（如脚手架、开发工具、数据同步工具）开源。
2. 维护好 README、文档和 Issue 回复，提升项目曝光度。
3. 开源项目前期回报很慢，适合长期投入、打品牌。

---

## 四、技术咨询 / 辅导

**适合人群**：有大厂面试经验、八股功底扎实的同学。

**形式**：
- 在[牛客](https://www.nowcoder.com/)、[lintcode](https://www.lintcode.com/) 担任辅导教师
- 在闲鱼/微信私下提供简历修改、模拟面试、技术辅导服务
- 加入技术答疑星球（如知识星球）

**收费参考**：
- 简历修改：100～300 元/份
- 模拟面试：200～500 元/小时
- 一对一辅导包：1000～3000 元/月

**建议**：
1. 入职后积累大厂面试经验再开始做辅导，说服力更强。
2. 初期可免费帮身边同学模拟面试，打磨流程、积累口碑。

---

## 五、参与竞赛 / Hackathon

**适合人群**：喜欢挑战、擅长快速原型开发的同学。

**推荐赛事**：
- [阿里云天池](https://tianchi.aliyun.com/)（算法 & 工程类赛事）
- [字节跳动青训营](https://youthcamp.bytedance.com/)（技术方向大赛）
- 各类 Hackathon（稀土掘金、SegmentFault 等平台会发布活动）

**建议**：
1. 比赛奖金不是主要目的，更重要的是积累作品、拓展人脉。
2. 可以和在校同学组队，以在职身份参赛往往有更强的工程实现能力。

---

## 六、AIGC 工具 / 自动化变现（新兴方向）

随着 AI 工具的普及，后端工程师可以借助 AI 提升生产效率并将其商业化：

- **搭建 AI 套壳产品**：用 OpenAI / Claude API 封装特定场景的工具（如简历生成器、代码审查机器人），在独立站或小程序上收费。
- **提示词工程 / Prompt 销售**：在 PromptBase 等平台出售高质量提示词。
- **自动化脚本服务**：为中小企业提供数据爬取、报表自动化等脚本服务。

**建议**：
1. 降低 API 成本是关键，合理设置调用限制和计费模型。
2. 选择小而美的垂直场景，避免和大平台直接竞争。

---

## 七、注意事项

1. **了解公司规定**：入职前仔细阅读劳动合同和保密协议，部分大厂禁止员工在外兼职或注册公司，违反可能影响转正或被辞退。
2. **时间管理**：大厂工作节奏较快，建议副业每周投入不超过 10 小时，避免影响本职工作。
3. **税务合规**：收入超过一定额度需要缴税，接外包或开设店铺时注意了解相关规定。
4. **先站稳脚跟**：建议入职 3～6 个月、工作相对稳定后再大力发展副业，优先建立良好的职场口碑。

## 总结

| 方向 | 启动难度 | 收益速度 | 时间投入 | 推荐指数 |
|------|----------|----------|----------|----------|
| 接私活 | 中 | 快 | 中高 | ⭐⭐⭐⭐⭐ |
| 技术博客 / 视频 | 低 | 慢 | 低中 | ⭐⭐⭐⭐ |
| 技术辅导 / 简历 | 低 | 中 | 低 | ⭐⭐⭐⭐ |
| 开源项目 | 中 | 很慢 | 中 | ⭐⭐⭐ |
| AIGC 工具 | 中高 | 中 | 中高 | ⭐⭐⭐⭐ |
| 竞赛 | 高 | 慢 | 高 | ⭐⭐⭐ |

**对于即将入职大厂的同学，短期内最推荐的方式是**：先专注本职工作、积累大厂经验，同时开始写技术博客建立个人品牌；稳定后再尝试接私活或做技术辅导，这是风险最低、可持续性最强的路径。
